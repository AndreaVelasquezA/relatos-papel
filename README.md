# 📚 Relatos de Papel - Full Stack Project

¡Bienvenido/a! Este repositorio contiene el desarrollo integral de la plataforma **Relatos de Papel**, un proyecto transversal del **Máster Universitario en Desarrollo Web**.

---

## 🎯 Finalidad del Proyecto
El objetivo principal es construir una aplicación **Full Stack de extremo a extremo**, cubriendo desde el diseño de microservicios hasta el despliegue en producción. El proyecto se divide en tres hitos clave:

1.  **Front-end (SPA):** Creación de una experiencia de usuario fluida con React.
2.  **Back-end (Microservicios):** Arquitectura escalable en Java con Spring.
3.  **Integración y Cloud:** Despliegue completo en entornos locales y públicos.

---

## 🛠️ Stack Tecnológico

### **Front-end 🎨**
* **React:** Uso intensivo de *Hooks* (prominentes y personalizados).
* **Diseño:** Estructura moderna con HTML5, CSS3 y JavaScript.

### **Back-end & Microservicios ⚙️**
* **Java & Spring:** Arquitectura orientada a microservicios con APIs RESTful.
* **Comunicación:** Eventos asíncronos y protocolos **WebSocket** para tiempo real.
* **Búsqueda Avanzada:** Implementación de **Elasticsearch** para consultas de alto rendimiento.
* **Integraciones:** * 📧 Mensajería externa vía SMTP (Gmail).
    * 🤖 Inteligencia Artificial mediante **Gemini API**.

### **Seguridad & DevOps 🔒**
* **Autenticación:** Sistema híbrido de **JWT** y *Phantom Token Pattern*.
* **Cloud:** Despliegue en **Vercel** (Front) y **Railway** (Back).

---

## 🏗️ Arquitectura del Sistema
El proyecto sigue el flujo transversal del máster, integrando:
- Comunicación basada en eventos.
- Persistencia de datos eficiente.
- Consumo de APIs de IA para potenciar la funcionalidad.
